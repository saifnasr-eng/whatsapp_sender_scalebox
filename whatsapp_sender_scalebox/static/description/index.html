Why this module?

Odoo lets you print or email a document, but there is no native way to send an Invoice, Sales Order, Purchase Order, Quotation, RFQ or POS Receipt straight to WhatsApp as a real file. This module adds a "Send via WhatsApp" button everywhere you need it, using the browser's native Web Share API — the exact same result as opening a PDF on your phone and tapping Share > WhatsApp. No public links, no third-party WhatsApp API subscription, no external integration.

Key Features

  • Customer Invoices — "Send via WhatsApp" button next to Print.
  • Sales Orders & Quotations — "Send via WhatsApp" button next to Send by Email.
  • Purchase Orders & RFQs — "Send via WhatsApp" button next to Send by Email.
  • POS Receipts — shares a pixel-perfect snapshot of the receipt exactly as displayed on screen, including any ZATCA QR code or other localization elements.
  • Always shares the real file — never a download link or public URL.
  • Automatic fallback: downloads the file when native sharing isn't supported (e.g. desktop Linux browsers), so it can be attached manually.
  • Zero core modifications — pure view inheritance (XML) and JS patching, 100% upgrade-safe.
  • Fully independent: no subscriptions, no external WhatsApp Business API required.

Compatibility

Works on Windows, Linux, Android and iOS/iPadOS, through the browser, PWA, or the Odoo Mobile App — wherever the device's Web Share API is available. On platforms without native file-sharing support, the module automatically downloads the file instead so it can be attached manually in WhatsApp.
